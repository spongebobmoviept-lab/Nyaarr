Connect Sonarr

Nyaarr reads your anime series and missing episodes from Sonarr.

Where do I find my Sonarr API key?
In Sonarr: Settings → General → the Security section near the bottom.

Connect Radarr

Used for the "Find Related Movies" feature — anime franchises often have movies too.

Where do I find my Radarr API key?
Same place as Sonarr: Settings → General → Security.

Connect TMDB optional

Only needed for "Find Related Movies." Free to get, skip if you don't need this yet.

Where do I get a TMDB API key?
Create a free account at themoviedb.org, then in your account settings go to API and request a key (choose "Developer" — instant approval for personal use).
